VÉRTICE — Manual Ilustrado

Attack Surface Mapping & Intelligence Gathering · família DEIVOSINT
Este manual é para usuários leigos. Cada seção tem um objetivo claro, telas anotadas com marcadores numerados e diagramas. Se tiver pressa, veja COMECE-AQUI.md — ele te leva ao primeiro resultado em 3 passos.

O que é o VÉRTICE

O VÉRTICE descobre, organiza e documenta a superfície de ataque de um alvo autorizado — todos os pontos pelos quais ele é visível na internet: domínios, subdomínios, IPs, tecnologias, serviços expostos, e-mails, certificados. Ele faz isso de forma passiva (sem atacar nada), guarda cada achado num diário de evidências à prova de adulteração e entrega um dossiê pronto para a próxima fase (pentest autorizado ou defesa).

Três ideias que dão nome à ferramenta — os três vértices:
  • Fonte — de onde veio cada informação (proveniência).
  • Identificador — a entidade observável (domínio, IP, e-mail...).
  • Vínculo — como as entidades se ligam (o grafo).

Como funciona (visão geral)

Você dá uma semente (ex.: um domínio). O VÉRTICE roda vários collectors passivos sobre ela, transforma cada achado em entidade no grafo, registra a evidência com um selo criptográfico e repete o processo sobre os novos achados, até a profundidade que você escolher.

Instalação — passo a passo por sistema

O VÉRTICE é Python puro: não instala pacote nenhum. Só precisa do Python 3.9 ou mais novo. Escolha a aba do seu sistema.

1
Instale o Python em python.org/downloads. Na primeira tela, marque “Add Python to PATH” antes de clicar em Install.
2
Abra o Prompt de Comando (tecle Win, digite cmd, Enter).
3
Confira: python --version.
4
Entre na pasta do VÉRTICE: cd C:\caminho\para\vertice.
5
Duplo-clique em launchers\vertice-demo.bat — ou rode os comandos do próximo capítulo.
1
O macOS já traz Python 3. Confirme no Terminal: python3 --version. Se pedir, instale as ferramentas de linha de comando (xcode-select --install).
2
No Terminal, entre na pasta: cd ~/Downloads/vertice.
3
Duplo-clique em launchers/vertice-demo.command (se o Gatekeeper reclamar: clique com o botão direito → Abrir).
1
Confirme o Python: python3 --version (quase toda distro já tem).
2
Entre na pasta: cd ~/vertice.
3
Rode o lançador: ./launchers/vertice-demo.sh (se precisar: chmod +x launchers/*.sh).

Investigação real

⚠️ Só investigue o que você tem autorização para investigar. O escopo definido no init é respeitado pelo VÉRTICE em toda coleta ativa.
1
Criar o engajamento com escopo e autorização:
$ python3 -m vertice init meu-caso --scope alvo.com --by "Contrato 2026-10" [ok] workspace criado: meu-caso escopo: ['alvo.com']
2
Coletar (passivo, profundidade 2):
$ python3 -m vertice run meu-caso --seed alvo.com --depth 2 [info] collectors ativos: crtsh, dns, fingerprint, pivot, rdap, wayback [crtsh] alvo.com -> 37 achado(s) 1 [dns] www.alvo.com -> 2 achado(s) ... === resumo === nodes 214 2 edges 389 evidence 403
  • 1 Cada linha mostra qual collector trouxe quantos achados (proveniência).
  • 2 Resumo final: tamanho do grafo e quantas evidências foram seladas.
3
Gerar o dossiê: python3 -m vertice report meu-caso -o meu-caso/dossie.html

Conectores opcionais (com chave de API)

Censys, Shodan, ZoomEye e FOFA ampliam a coleta, mas exigem chave. Ficam desligados até você colar a credencial — que fica só no seu workspace.

$ python3 -m vertice creds meu-caso --set censys_token=SEU_ID:SEU_SECRET [ok] credencial 'censys_token' salva (apenas local).
ConectorCredencialFormato
Censyscensys_tokenAPI_ID:API_SECRET
Shodanshodan_keychave
ZoomEyezoomeye_keychave
FOFAfofa_keyemail:key
Na próxima vez que você rodar run, o conector com chave entra automaticamente. Sem chave, ele é pulado — sem erro.

Gerar relatórios

Duas formas:

  • Arquivo: python3 -m vertice report CASO -o dossie.html — gera um HTML autocontido (pode enviar por e-mail, imprimir, anexar).
  • Bancada web: python3 -m vertice bench CASO — sobe http://127.0.0.1:8713 e mostra o dossiê ao vivo (recarrega o grafo a cada acesso). Útil enquanto a coleta ainda roda.

Cadeia de custódia — por que o VÉRTICE é diferente

Cada evidência é selada com um hash SHA-256 que inclui o hash da evidência anterior. É uma corrente: mexer em um elo quebra todos os seguintes.

verify reprocessa tudo
$ python3 -m vertice verify meu-caso [ok] cadeia íntegra — 403 registros 1 head: bf39310fa452b6425d... 2
  • 1 Se algum registro tivesse sido alterado, apareceria [FALHA] apontando o número do registro.
  • 2 O head é a "impressão digital" de toda a investigação — anote-o num relatório para provar integridade depois.

Glossário

Superfície de ataqueTudo do alvo que é visível/alcançável de fora.
OSINTInteligência de fontes abertas (dados públicos).
PassivoColeta que não interage com o alvo (não "bate" nele).
EntidadeUm identificador: domínio, IP, e-mail, tecnologia...
GrafoEntidades (nós) ligadas por relações (arestas).
CollectorUm coletor de uma fonte específica (crt.sh, DNS...).
PivôSaltar de um identificador para buscas em vários serviços (ideia do Mitaka).
ProveniênciaRegistro de qual fonte afirmou cada achado.
Cadeia de custódiaProva de que as evidências não foram adulteradas.
WorkspaceA pasta de um caso (grafo + evidências + config).
FingerprintReconhecer a tecnologia por assinaturas (ideia do BuiltWith).
Favicon hashImpressão do ícone do site — liga ativos do mesmo dono (ideia do FOFA).
